# 引用风格示例

选择一种，并在同一轮回答中保持一致。

## compact（默认）

```markdown
结论：v2.4.0 于 2026-03-12 发布，新增批量导入。

来源：
- [Release notes v2.4.0](https://example.com/releases/v2.4.0)
- [Official changelog](https://example.com/changelog)
```

## section

```markdown
正文……

***

来源
- [Release notes v2.4.0](https://example.com/releases/v2.4.0)

***
```

## plain

```text
来源：
Release notes v2.4.0 - https://example.com/releases/v2.4.0
```

## 规则

- 只列真正使用过的来源
- 单一来源注明「仅单一来源」
- 没有权威来源时写「未找到权威来源」
- 不要在正文开头、中间和结尾重复堆来源
