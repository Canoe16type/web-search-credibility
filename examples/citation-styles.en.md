# Citation Style Examples

Choose one style and stay consistent within a response.

## compact (default)

```markdown
Conclusion: v2.4.0 was released on 2026-03-12 and adds bulk import.

Sources:
- [Release notes v2.4.0](https://example.com/releases/v2.4.0)
- [Official changelog](https://example.com/changelog)
```

## section

```markdown
Body...

***

Sources
- [Release notes v2.4.0](https://example.com/releases/v2.4.0)

***
```

## plain

```text
Sources:
Release notes v2.4.0 - https://example.com/releases/v2.4.0
```

## Rules

- List only sources actually used
- Label single-source claims
- Say "no authoritative source found" when applicable
- Do not repeat sources at the beginning, middle, and end
