# 权威来源清单与检索模板

不绑定任何国家、平台或搜索厂商。

## 通用优先级

1. 官方原文 / 标准原文 / 一手公告
2. 官方仓库、Release、变更日志
3. 官方帮助中心、知识库
4. 有编辑与署名的可靠二手来源
5. 社区维护资料（必须标注非官方）

## 按领域

### 软件与 API

官方文档 `docs.<domain>` / `<domain>/docs`；官方仓库 README、Releases、CHANGELOG、Issues；包管理器 npm、PyPI、Maven Central、crates.io；标准 W3C、IETF RFC、ISO/IEC、ECMA。

```text
<product> official docs <topic>
<product> release notes <version>
<repo> GitHub releases <version>
<error code> official documentation
```

### 政策、法规与公共服务

政府/监管机构官网；法规、标准、政策原文；官方公告、监管披露；国际组织官网（按主题）。

```text
<policy name> official site
<law/regulation> full text
<agency> announcement <date>
```

不要把某个国家的域名清单当全球规则；换成目标地区官方站点。

### 企业与金融

公司官网、投资者关系页；交易所公告、监管披露；企业注册/信用数据库（按地区）；年报、招股书、财报原文。

```text
<company> investor relations annual report
<company> official announcement <event>
<ticker> exchange filing
```

### 学术与医学

DOI、PubMed、arXiv、期刊官网；大学、研究机构、政府卫生部门；系统综述、指南、临床试验注册。

```text
<topic> systematic review
<topic> site:pubmed.ncbi.nlm.nih.gov
<guideline> official
```

### 游戏、动漫与虚构作品

官方站点、官方 Wiki、官方公告；官方社交媒体/新闻页；社区 Wiki 仅作补充并标注非官方；数值、版本、价格、掉落以官方或实测为准。

```text
<work> official wiki <term>
<work> official announcement <update>
<work> <term> wiki
```

多语言：先用用户语言确认名称，再用作品原语言或英文复核。

### 商品与价格

官方商店/官网价格；官方参数页；电商页面仅作线索，回到官方核对。

## 判断来源质量

优先：作者/机构明确、有发布日期、引用一手来源、是原文、与多个独立来源一致。

警惕：无署名聚合页、标题党、内容农场、过期页面、只给结论不给依据。
